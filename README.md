BoolFitness è un progetto **full‑stack** sviluppato come lavoro di gruppo durante il corso Boolean.  
Questa repository raccoglie e organizza in una **monorepo** sia il frontend che il backend, originariamente creati in repository separate dal team.
Entrambe le parti mantengono la **cronologia dei commit originali**, importata tramite `git subtree`.
L’obiettivo era simulare un flusso di lavoro reale, collaborando su più codebase e gestendo versionamento, integrazione e sviluppo coordinato.

## 🎯 Obiettivi del Progetto

- Sviluppare un’applicazione completa front‑end + back‑end.
- Lavorare in team seguendo un flusso di sviluppo condiviso.
- Gestire repository multiple e integrarle in una struttura unica.
- Applicare concetti di version control e collaborazione.
- Simulare un ambiente di lavoro reale con divisione dei ruoli.
